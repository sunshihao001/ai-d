# ai-d｜AI 与人协调：通用专业认知内核（初步定位）

## 2026-11-07｜上位愿景：让普通人在 AI 时代获得真实的学习、谋生与发展能力

**目标来源：用户在现有 ai-d／跨项目认知研究过程中明确提出的方向扩展。状态：上位目标草案与研究定位已记录；尚非已交付的社会化产品。** 这不是简单增加更多知识类别，而是将 ai-d 原有“专业认知内核”放入更大的人的发展目标之中。

> **长期目的（G0）**：让缺少专业术语、职业经验、经济资源或技术背景的人，也有机会借助通用 AI 和成熟专业知识，更准确理解自身处境、学习新能力、找到可行谋生方式、作出自主决定、完成实际工作，并在技术与社会持续变化中扩大选择空间，逐步改善其现实生活。所谓“安家立业”是人的多样化目标之一，不能预设每个人都追求创业、交易或单一收入指标。

**上位愿景 ≠ 当前可用能力**：目前仓库仍主要是专业认知/人机协作的可复用研究、知识组织、Draft Skill 与局部测试。没有建成全领域的人生顾问、自动就业系统、财富创造系统或跨模型已验证的产品，也不能保证个人收入、职业选择或其他生活结果。

### 从人的真实问题理解系统范围，而不是给所有领域建固定专家和模块

| 人的现实需求（可重叠、可扩展） | 需要的不同专业理解 | 可能提供的实际帮助 |
|---|---|---|
| **基本稳定与安全** | 健康、工作安全、住房、基本资源、法律与公共服务的适用条件 | 理解信息和办理路径、风险识别、专业转介；重要医疗/法律决定不以 AI 猜测替代专业核查 |
| **学习与认知成长** | 学习科学、专业知识、逻辑与批判思维、信息素养、专家问题表征 | 把朦胧想法转化为可理解、可练习、可迁移的知识与技能 |
| **职业、收入与创造** | 劳动市场、职业训练、经济学、管理、创业、工程、产品和行业机制 | 比较实际路径，复用成熟工具，完成作品、工作与技能证据；不承诺成功 |
| **独立判断与自我发展** | 决策理论、系统思维、价值取舍、长期目标、多方案与反证 | 看见不确定性、资源约束和竞争解释，提高选择质量而不替用户设定人生目标 |
| **关系、协作与社会参与** | 沟通、社会心理、组织、制度、权利与责任 | 帮助理解协作问题、实际沟通与可行社会资源，尊重他人自主性 |
| **适应 AI 与未来变化** | 产业变化、数字技能、工具协作、知识迁移、风险管理和终身学习 | 根据新证据修订职业与项目计划，降低对单一模型、单一技能或旧建议的依赖 |

领域范围保持开放，不要求同时覆盖所有行业。**一个真实问题往往跨越多个领域**，例如重新就业同时涉及技能、区域市场、收入成本、风险、学习与家庭资源；不能把它压缩成“推荐岗位”或“写一份提示词”。

### 正交的三个维度：不可混成固定运行步骤

1. **人的现实目标与处境**：现在希望怎样生活、能够选择什么、受哪些资源与环境制约、什么变化才算有价值。
2. **AI 与人共同拥有的可迁移能力**：原有七项并行认知能力继续有效，包括理解目标、专家知识、发现未知、判断、授权内行动、证据纠错和长期继承；需要时补入学习、沟通、经济与社会领域的专业知识。
3. **具体领域的事实与实践**：Meme 研究/Blix、制造业、职业发展、家庭生活及未来项目各自保留领域知识、工具、权限与真实结果。ai-d 不因上位目标扩展就替它们编造数据或越权执行。

**工作流、外挂大脑、专业知识组织、Cognitive Core Skill、Grok Bot 是实现手段或局部应用，不是项目的最终目的。** 各消费项目可以复用通用能力，但不能因为 ai-d 的社会化愿景就自动改变自己的明确业务边界。例如 Meme 项目继续以只读市场研究/产品交付为主体，不把高风险交易说成解决普通人生计的保证。

### 如何判断能否在 AI 行业形成真正的差异

独特价值不能靠“框架更复杂、专家更多、文档更厚或模型更强”来证明。候选差异应由实际证据检验：**低专业门槛、跨域问题理解深度、成熟专业证据的正确适用、完成真实行动、保留人的独立选择、可追溯失败经验，以及不同领域的可重复效果。**

在允许的范围内可测量：某人是否获得了此前缺少的可行选项、可验证技能/作品、正确决策所需证据、减少的错误或返工、可独立完成的任务、成本与时间；中长期生活效果还受外部条件影响，不能未经对照归因于 ai-d。禁止用 AI 自评分、单次演示、Skill 安装或文件数宣称实现了社会价值或竞争优势。

### 外部成熟研究与其边界

- [UNDP《Human Development Report 2025》](https://hdr.undp.org/content/human-development-report-2025)：人的选择机会与能动性是目标，不只是 AI 技术性能。
- [能力方法（Stanford Encyclopedia of Philosophy，2025修订）](https://plato.stanford.edu/entries/capability-approach/)：资源与知识只有在真实条件允许转化时才成为人的实质机会；理论不能代替产品用户研究。
- [ILO 2025 GenAI 职业暴露研究](https://www.ilo.org/publications/generative-ai-and-jobs-refined-global-index-occupational-exposure)：职业暴露不等于实际失业，需区分职业、任务和现实经济条件。
- [OECD《Skills in the AI Age》(2026)](https://www.oecd.org/en/publications/skills-in-the-ai-age_972bd15e-en/full-report/component-4.html)：基础技能、AI 素养、批判性思考与持续学习同时重要。
- [UNESCO AI competency framework (2024，2026更新)](https://www.unesco.org/en/articles/ai-competency-framework-students)：理解、应用和创造及以人为中心的 AI 使用，适用对象主要是教育，向成人生计支持迁移需要实际验证。
- [QJE《Generative AI at Work》(2025)](https://academic.oup.com/qje/article/140/2/889/7990658)：特定客服工作中 AI 提高产出的实证，不能当成所有职业的增益保证。
- [NIST AI RMF](https://www.nist.gov/publications/artificial-intelligence-risk-management-framework-ai-rmf-10)：AI 应用风险需要按具体场景治理，不因通用愿景扩大私有数据、医疗/法律或财务行动权限。

**现阶段取舍**：先保留并深化已积累的 ai-d 认知内核，让它在真实跨领域任务上形成可验证的能力与成果；再决定具体产品形态与面向公众的交付方式，不把远期愿景立刻翻译成新的超级架构、全覆盖专家制度或大规模技能包。

## 一、为什么建立这个仓库？

人往往只能先表达一个朦胧、具体、甚至不完整的想法；随着研究深入，问题的定义、真正值得追求的目标、可选方法与人的偏好都可能变化。

例如，一个最初只想寻找可跟单钱包的目标，可以在研究资金关系、行为机制、专业产品与实际反馈后，逐步演变成更完整的市场智能研究目标。

这种演变不是“需求不稳定”的简单错误，而是**人与 AI 共同发现更有价值问题**的过程。AI 不应只执行一句话的字面意思，也不应擅自替人决定人生目的或重大价值取舍。

**本仓库的核心问题：如何让人只需用自然语言表达意图、感受、反馈和重要选择，AI 就能主动承担专业理解、开放研究、方案比较、授权内执行、验收、反证和持续修正，同时识别目标层级的变化，并在工作结束后产生下一轮真正有价值的新认识？**

## 二、初步目标（可以随着证据继续演化）

研究、保存并检验一组**跨模型、跨工具、跨专业领域可迁移的人机协作认知能力**，使未来具体的 AI 工作流在调用这些知识时：

1. **理解意图，也理解目标变化。** 区分人的原始表述、真实目的、暂时假设、约束、价值取舍，以及 AI 提出的新目标候选；识别任务层、方法层、产品层和长期方向的改变。
2. **主动发现未知。** 不只按用户已知的术语找答案；从专业概念、原始资料、不同解释、跨领域联系和失败反例中发现更重要的问题。
3. **形成成熟选择。** 对同一目标生成有真实差异的方案，比较证据、价值、成本、风险、可推翻条件；能推荐而不是一味列选项。
4. **承担可授权的专业工作。** 将研究连接到设计、实现、测试、质量检查与可追溯交付；不把不必要的技术决策反复交回用户。
5. **独立核查与纠错。** 区分事实、资料作者主张、模型推论、假设、离线测试和真实运行；在新证据出现时主动修正，必要时停止或改变方案。
6. **从结果继续思考。** 每次有实质成果后，重新审视目标是否变化、知识与方法是否还能改进、出现了哪些有价值的新方向，选择下一项最值得做的事。
7. **让可靠经验迁移。** 保留专业知识的原始来源、适用边界、反例及实际结果；按当前问题选择使用，不把全部历史提示词变成永久强制规则。

**人的职责**：决定个人价值、重大方向、重要资源投入、隐私与外部高风险授权，反馈实际体验。**AI 的职责**：在获准的环境和工具范围内，尽可能承担专业研究、判断支持、实施与验收；透明报告未完成与未知。人可以随时改变目标和停止任务。

## 三、“内核”意味着什么，不意味着什么？

本仓库所说的内核，首先是**通用认知知识与协作方法的参考源**，不是系统内核、模型权重、一个万能提示词，也不是把所有任务编排成统一状态机。

未来不同 Skill 或工作流可以按需借用：目标理解、研究方法选择、专业知识适用性判断、证据与反证、方案决策、人机权限协作、任务后复盘与新目标发现等知识。

它们仍要根据各自专业领域、工具权限和任务环境实施具体流程。**可迁移的是方法与判断原则，不是每个领域的事实、阈值或执行动作都通用。** 保存到仓库也不等于模型已经“学会”，必须有正确的调用、解释和任务验证。

### 暂不预设的技术选择

- 不预设固定 Bot 数量、专家委员会、九阶段/几十项动作、单一 Agent SDK、知识图谱数据库或统一工作流引擎。
- 不把项目写成另一套大型系统提示词，不强制每次回答使用所有认知方法。
- 不要求把旧知识全文一次性搬入；先保持来源可追溯、内容有选择、结论可反驳。
- 不声称目前已实现跨会话自主执行、自动持续研究或可量化的能力提升。

## 四、知识如何逐步建设？

优先积累四种相互关联、但不混同的材料：

| 资产 | 要保存的内容 | 不能误当成什么 |
| --- | --- | --- |
| **专业原理** | 真实的认知科学、人机协作、推理、决策、知识组织等来源与适用条件 | 一条强制执行的提示词规则 |
| **研究方法** | 如何提出问题、检索、关联、竞争解释、反证、判断何时停止 | 每轮必须走完的固定流程 |
| **真实案例** | 原始意图 → 关键证据 → 判断改变 → 可检查结果 → 错误与反例 | AI 自评成功或展示用故事 |
| **当前决策与待验证主张** | 为什么选择某种做法、什么证据会改变选择、下一项高价值验证 | 永久正确的架构承诺 |

初期先索引现有关于目标演化、认知理解、多轮协作、知识污染、研究质量、Agent 状态与人类监督的历史资料。引用和原始专业认识可按主题保留，历史设计方案可追溯但不自动成为现行指令。公开仓库不上传私人对话原文、身份信息、秘钥或无权公开的第三方材料。

**每项新研究进入仓库的标准**：与人机协调或跨任务认知能力实质相关；说明来源/日期/证据等级；写清新认识改变了哪个判断、何时有用、何时不适用；允许保留 UNKNOWN。不是搜索过或总结过就等于验证过。

## 五、未来可能怎样演化？（候选，不是预定路线）

| 方向 | 意义 | 触发条件 |
| --- | --- | --- |
| **A. 开放的专业认知知识库** | 研究、比较、归档、发现知识关联 | 先证明知识能在新任务中被准确调用 |
| **B. 可复用的认知内核 / Skill 知识源**（当前优先） | 给不同 AI 工作流提供通用判断方法与使用边界 | 在至少两个不同领域的任务中看到可核查收益 |
| **C. 自主 Agent 工作平台** | 进一步负责持续执行、恢复、工具编排与审批 | 出现仅靠现有 GPT + GitHub 无法解决的真实运行缺口 |
| **D. 人机协作可视化产品** | 展示目标演化、方案、证据和任务状态 | 用户体验证明文档方式已造成明显障碍 |

当前推荐 **A 打底，向 B 验证**。C 和 D 保留可能性，但不是先决条件。随着新证据、技术与用户目标变化，可以改变路线。

## 六、第一批验证问题

**案例一｜目标演化：** 从“寻找可跟单钱包”到“市场智能系统”，测试 AI 是否正确区分用户原意、新知识推动的目标升级、AI 未经确认的推断及真正值得保留的方向。

**案例二｜专业研究：** 在新领域，用“普通研究”和“按需调用本仓库方法”分别解决同一问题，比较是否提高了事实准确性、关键未知发现、方案判断和可执行性；警惕因更多提示词造成离题、成本提高或误判。

**案例三｜长期任务恢复：** 区分保存历史对话、恢复未完成执行状态、保存经过验证的方法，以及新问题中能否正确调取；不能因材料已存储就宣称 AI 已获得可靠长期记忆。

判断标准是**真实问题处理质量**，不是文档数量、架构层数、Bot/Skill 个数或 AI 自我评分。

## 七、当前状态与下一步

- **已确定**：本仓库的初步目标和边界；未来可以作为多种 AI 工作流的通用认知知识来源。
- **尚未实现**：完整知识迁移、专业研究评测、自动调用机制、独立 Agent 平台。
- **下一项最有价值的行动**：先登记现有七八月认知研究、10月去约束研究及11月最新人机协作研究的**来源与有效认识**，同时选一个跨领域真实问题检验是否真的改善判断；再决定要不要新增目录或代码。
