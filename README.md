## 一、为什么建立这个仓库？

人往往只能先表达一个朦胧、具体、甚至不完整的想法；随着研究深入，问题的定义、真正值得追求的目标、可选方法与人的偏好都可能变化。

例如，一个最初只想寻找可跟单钱包的目标，可以在研究资金关系、行为机制、专业产品与实际反馈后，逐步演变成更完整的市场智能研究目标。

这种演变不是“需求不稳定”的简单错误，而是**人与 AI 共同发现更有价值问题**的过程。AI 不应只执行一句话的字面意思，也不应擅自替人决定人生目的或重大价值取舍。

**本仓库的核心问题：如何让人只需用自然语言表达意图、感受、反馈和重要选择，AI 就能主动承担专业理解、开放研究、方案比较、授权内执行、验收、反证和持续修正，同时识别目标层级的变化，并在工作结束后产生下一轮真正有价值的新认识？**

## 二、初步目标（可以随着证据继续演化）

研究、保存并检验一组**跨模型、跨工具、跨专业领域可迁移的人机协作认知能力**，使未来具体的 AI 工作流在调用这些知识时：

1. **理解意图，也理解目标变化。** 区分人的原始表述、真实目的、暂时假设、约束、价值取舍，以及 AI 提出的新目标候选；识别任务层、方法层、产品层和长期方向的改变。
2. **主动发现未知。** 不只按用户已知的术语找答案；从专业概念、原始资料、不同解释、跨领域联系和失败反例中发现更重要的问题。
3. **形成成熟选择。** 对同一目标生成有真实差异的方案，比较证据、价值、成本、风险、可推翻条件；能推荐而不是一味列选项。
4. **承担可授权的专业工作。** 将研究连接到设计、实现、测试、质量检查与可追溯交付；不把不必要的技术决策反复交回用户。
5. **独立核查与纠错。** 区分事实、资料作者主张、模型推论、假设、离线测试和真实运行；在新证据出现时主动修正，必要时停止或改变方案。
6. **从结果继续思考。** 每次有实质成果后，重新审视目标是否变化、知识与方法是否还能改进、出现了哪些有价值的新方向，选择下一项最值得做的事。
7. **让可靠经验迁移。** 保留专业知识的原始来源、适用边界、反例及实际结果；按当前问题选择使用，不把全部历史提示词变成永久强制规则。

**人的职责**：决定个人价值、重大方向、重要资源投入、隐私与外部高风险授权，反馈实际体验。**AI 的职责**：在获准的环境和工具范围内，尽可能承担专业研究、判断支持、实施与验收；透明报告未完成与未知。人可以随时改变目标和停止任务。

## 三、“内核”意味着什么，不意味着什么？

本仓库所说的内核，首先是**通用认知知识与协作方法的参考源**，不是系统内核、模型权重、一个万能提示词，也不是把所有任务编排成统一状态机。

未来不同 Skill 或工作流可以按需借用：目标理解、研究方法选择、专业知识适用性判断、证据与反证、方案决策、人机权限协作、任务后复盘与新目标发现等知识。

它们仍要根据各自专业领域、工具权限和任务环境实施具体流程。**可迁移的是方法与判断原则，不是每个领域的事实、阈值或执行动作都通用。** 保存到仓库也不等于模型已经“学会”，必须有正确的调用、解释和任务验证。

### 暂不预设的技术选择

- 不预设固定 Bot 数量、专家委员会、九阶段/几十项动作、单一 Agent SDK、知识图谱数据库或统一工作流引擎。
- 不把项目写成另一套大型系统提示词，不强制每次回答使用所有认知方法。
- 不要求把旧知识全文一次性搬入；先保持来源可追溯、内容有选择、结论可反驳。
- 不声称目前已实现跨会话自主执行、自动持续研究或可量化的能力提升。

## 四、知识如何逐步建设？

优先积累四种相互关联、但不混同的材料：

| 资产 | 要保存的内容 | 不能误当成什么 |
| --- | --- | --- |
| **专业原理** | 真实的认知科学、人机协作、推理、决策、知识组织等来源与适用条件 | 一条强制执行的提示词规则 |
| **研究方法** | 如何提出问题、检索、关联、竞争解释、反证、判断何时停止 | 每轮必须走完的固定流程 |
| **真实案例** | 原始意图 → 关键证据 → 判断改变 → 可检查结果 → 错误与反例 | AI 自评成功或展示用故事 |
| **当前决策与待验证主张** | 为什么选择某种做法、什么证据会改变选择、下一项高价值验证 | 永久正确的架构承诺 |

初期先索引现有关于目标演化、认知理解、多轮协作、知识污染、研究质量、Agent 状态与人类监督的历史资料。引用和原始专业认识可按主题保留，历史设计方案可追溯但不自动成为现行指令。公开仓库不上传私人对话原文、身份信息、秘钥或无权公开的第三方材料。

**每项新研究进入仓库的标准**：与人机协调或跨任务认知能力实质相关；说明来源/日期/证据等级；写清新认识改变了哪个判断、何时有用、何时不适用；允许保留 UNKNOWN。不是搜索过或总结过就等于验证过。

## 五、未来可能怎样演化？（候选，不是预定路线）

| 方向 | 意义 | 触发条件 |
| --- | --- | --- |
| **A. 开放的专业认知知识库** | 研究、比较、归档、发现知识关联 | 先证明知识能在新任务中被准确调用 |
| **B. 可复用的认知内核 / Skill 知识源**（当前优先） | 给不同 AI 工作流提供通用判断方法与使用边界 | 在至少两个不同领域的任务中看到可核查收益 |
| **C. 自主 Agent 工作平台** | 进一步负责持续执行、恢复、工具编排与审批 | 出现仅靠现有 GPT + GitHub 无法解决的真实运行缺口 |
| **D. 人机协作可视化产品** | 展示目标演化、方案、证据和任务状态 | 用户体验证明文档方式已造成明显障碍 |

当前推荐 **A 打底，向 B 验证**。C 和 D 保留可能性，但不是先决条件。随着新证据、技术与用户目标变化，可以改变路线。

## 六、第一批验证问题

**案例一｜目标演化：** 从“寻找可跟单钱包”到“市场智能系统”，测试 AI 是否正确区分用户原意、新知识推动的目标升级、AI 未经确认的推断及真正值得保留的方向。

**案例二｜专业研究：** 在新领域，用“普通研究”和“按需调用本仓库方法”分别解决同一问题，比较是否提高了事实准确性、关键未知发现、方案判断和可执行性；警惕因更多提示词造成离题、成本提高或误判。

**案例三｜长期任务恢复：** 区分保存历史对话、恢复未完成执行状态、保存经过验证的方法，以及新问题中能否正确调取；不能因材料已存储就宣称 AI 已获得可靠长期记忆。

判断标准是**真实问题处理质量**，不是文档数量、架构层数、Bot/Skill 个数或 AI 自我评分。

## 七、当前状态与下一步

- **已确定**：本仓库的初步目标和边界；未来可以作为多种 AI 工作流的通用认知知识来源。
- **尚未实现**：完整知识迁移、专业研究评测、自动调用机制、独立 Agent 平台。
- **下一项最有价值的行动**：先登记现有七八月认知研究、10月去约束研究及11月最新人机协作研究的**来源与有效认识**，同时选一个跨领域真实问题检验是否真的改善判断；再决定要不要新增目录或代码。
