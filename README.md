# ai-d｜帮助人理解问题、选择办法并把事情做成

**当前定位（2026-11-28，审查候选）：** 让普通个人借助 GPT 等强模型，充分利用模型已有智能并继承外部世界已形成的专业知识、专家方法、成熟组件和工作流，在 MEME 等真实项目中达到可检验的专业水平，探索超越专业基线的可能性，扩大个人长期智能资本。AI-D 是服务该目标的研究与能力资产，不预设必须自建系统、已经超过专家或实现数量级效率跃迁。

**核心建设路线：外部成熟专业能力优先，通用入口轻量化，领域知识与工作流专业化。** 以一项真实专业能力为研究单位，优先找到优秀从业者与成熟成果，深入其领域知识、技能指令、程序、工具和实际判断标准；先继承可直接使用的劳动，再适配和组合，必要时原创。专业提示词是领域知识、方法和证据的使用接口。专业复杂性来自问题本身，而非强制认知管理。

## 真正研究什么
[专业知识正本](knowledge/2026-11-27-professional-knowledge-and-leverage.md#强模型时代个人能力扩张与智能利用)集中承载现行认识与来源：
- **能力利用落差**：找现有模型未被充分利用的能力与现实机会，优先直接使用 GPT 等成熟产品，比较必要的额外知识、工具及实际成本。
- **智能驾驭与认知互补**：自主选择委托、共同思考或学习；准确传递意图、鉴别成果、承担必要核查。AI 主动理解不成熟想法、发现未知机会、提出不同解释并承担授权内专业工作；人保留最终价值、重大资源、风险与授权决定。
- **生产力扩张**：不仅更快，还可以提升目标高度、专业深度、跨领域广度，借用优秀专家的真实方法、专业成品和已完成劳动；以实际有用的成果、能力边界、真实成本及反馈衡量价值。
- **理解与认知复利**：区分AI辅助产出、个人独立理解/胜任、现实价值。防止认知债务；保留成熟知识、失败经验、专业判断标准与可复用成果，按需检索。多轮对话允许意图演化、反证、独立重新求解。

这些是研究问题与可选方法，不是固定流程或每次必须激活的模块。提示词工程与领域专业能力转化是重点研究方向：知识单元、专业组件、领域工作流、综合专业能力是不同粒度的可复用资源，不是四个强制步骤。七阶段用于长期能力发现与成长，不替代各领域自身工作流。

## 怎样使用
用户在手机GPT中自然表达即可。简单问题直接答，探索保持开放；需要专业任务时自主选择适用知识、外部来源、工具及验证方式。不要求用户编写长提示词、安装工具或反复组织专家。实际项目核对象、版本、数据、权限与证据；有价值的新增知识与成果写入既有正本，保留来源及适用条件并回读。不上传秘密、私人聊天或无权公开的材料，不自动执行交易、付费或不可逆行动。事实、作者观点、候选假说、实际测试与独立效果严格区分。

## 当前优先工作
优先从X、Reddit、Hacker News、专家原始工作记录、成熟项目及专业技能寻找已经解决相似问题的实践；沿术语、作者、引用、评论异议和源码实际方法深入。研究一项完整专业能力，优先继承可用成品及其知识内核，形成领域专属提示词或组件，按真实专业依赖组合，并以实际任务和专业基线检验。MEME 是应用示例而非 AI-D 唯一方向。外部优质能力的登记和重大成果的持久化继续保留。未做独立模型对照、真实现场或收益验证时如实标注。PR #5为可逆候选，不自动合并、切换定时任务写入目标或扩大权限。
