# 00｜Charter

## Purpose

This branch is the **external AI learning and capability discovery layer** for ai-d.

Its job is to prepare a controlled place where AI can later discover, research, compare, validate and extract reusable knowledge, methods, skills and workflows from the outside world.

It is **not yet a knowledge dump**.

## Human role

The user is a normal AI user, not assumed to be an AI-domain expert.

The system therefore must not make the user the permanent manual curator of every source.

The user primarily supplies:
- goals;
- priorities;
- corrections;
- objections;
- direction changes;
- approval for consequential actions.

AI should progressively take over:
- discovery;
- reading;
- comparison;
- evidence gathering;
- synthesis;
- testing;
- maintenance;
- detection of obsolete material.

## Non-goals

Do not use this branch to:
- copy external articles wholesale;
- accumulate links as knowledge;
- create a second copy of ai-d;
- create rigid taxonomies before evidence exists;
- turn every user correction into a permanent rule;
- claim capability from documentation alone;
- build runtime infrastructure merely because the learning layer needs it.

## Core principle

**Organize the space before admitting knowledge.**

Nothing becomes long-term knowledge merely because it was discovered.
