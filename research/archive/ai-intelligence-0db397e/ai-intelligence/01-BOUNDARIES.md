# 01｜Boundaries

## Main repository vs this branch

### ai-d main
Long-term:
- goals;
- durable knowledge;
- validated methods;
- project relationships;
- durable lessons;
- accepted capabilities.

### ai-intelligence
Frontier:
- discoveries;
- research candidates;
- source records;
- evidence;
- competing interpretations;
- experiments;
- candidate methods;
- candidate skills/workflows;
- rejected/deferred material.

## Boundary rule

The default direction is:

External source
→ discovery
→ research
→ evidence
→ candidate
→ test
→ adoption decision
→ only then possible promotion to ai-d main.

Promotion is not automatic.

## Do not duplicate

If something already exists in ai-d, link/refer to it rather than copying it into this branch unless the branch specifically needs a temporary research record.
