# 2026-11-23｜“信息揽客”带来的产品方向收缩：从宏大主动 AI 转向信息价值链

> **状态：CURRENT DESIGN DIRECTION / NOT YET INDEPENDENTLY VALIDATED**
>
> 本记录不是把“信息揽客”确立为 ai-d 的最终产品名称，也不是新增一套强制工作流。它记录一次重要的方向收缩：把近期过于宏观的“主动 AI / 个人智能体 / 外部大脑”讨论，落到一个可以真实验证的具体入口。

## 1. 新认识

“收集信息”本身正在快速商品化。AI 已经能够低成本完成大范围搜索、摘要和行业扫描，因此：

> **“我能帮你找到更多信息”不是足够强的长期价值。**

真正值得验证的价值链更接近：

**信息 → 筛选 → 判断 → 连接资源/专业人士 → 形成可执行成果 → 结果反馈**

其中：

- **信息获取**：基础能力，不应成为项目差异化目标。
- **筛选与判断**：从海量信息中识别真信号、噪音、与当前目标真正相关的变化，以及可能推翻当前判断的证据。
- **连接专业人士/资源**：AI 可以总结公开信息，但现实中的经验、信任、关系和非公开知识仍可能需要真人与资源网络。
- **落地**：把发现转成客户/用户能够直接使用的方案、资源清单、试点路径、行动步骤或其他具体成果。
- **反馈**：真实结果反过来检验判断是否正确，并修正后续筛选标准和方法。

## 2. “信息揽客”在 ai-d 中的正确位置

暂不把“信息揽客”定义成整个 ai-d，也不把它扩张成“超级智能体”。

更准确的定位：

> **信息揽客是一个具体入口：AI 替用户持续关注外部世界，把与用户当前目标有关、可能改变判断、创造机会或值得进一步验证的东西带回来。**

关键不是“搜得全”，而是：

> **在用户没有主动提问时，发现什么值得他知道。**

例如用户正在建设一个项目，AI 不只是等待“帮我搜索某主题”，而可以发现：

1. 新项目/新技术/新案例；
2. 与当前方案存在实质关系；
3. 其中可能存在支持、反例、替代路线或新机会；
4. 判断它是否值得打扰用户；
5. 只有达到价值阈值才推进研究；
6. 最终说明它改变了什么判断，是否需要行动。

## 3. 与近期“主动 AI”研究的关系

近期讨论得到的：

- Proactive AI
- Mixed-Initiative
- Agent
- Memory
- RAG
- Multi-Agent
- World Model
- Self-generated Goals

都不再作为项目目的。

它们只是回答具体问题的技术/认知能力：

| 问题 | 可借用能力 |
|---|---|
| 怎么发现外部变化？ | Proactive / monitoring |
| 怎么判断是否值得打扰？ | Initiative arbitration / value of information |
| 怎么研究？ | Research agent / tools |
| 怎么调用已有知识？ | Memory / RAG |
| 怎么执行复杂工作？ | Agent / workflow |
| 怎么理解人与环境？ | Situation awareness / world model |
| 怎么让多个能力协作？ | Multi-agent（仅在确有需要时） |

**不能反过来因为这些技术存在，就把 ai-d 重新定义成 Agent 平台。**

## 4. 对 ai-d 原有目标的修正

保留：

- 人只需用自然语言表达目标、反馈和重要选择；
- AI 负责专业问题表征、研究、比较、执行、验证和修正；
- AI 可以发现用户没有想到的问题；
- AI 不得擅自接管人的长期价值目标；
- 外部信息必须经过证据、适用性和实际结果检验；
- 信息、知识、能力和结果不能因为“保存进 GitHub”就被视为已验证。

进一步收缩：

> **AI 的主动性首先应该表现为“主动发现有价值的外部变化”，而不是“主动做越来越多事情”。**

因此评价主动性的标准不是活动量，而是：

- 是否发现了用户原本不知道的重要信息；
- 是否减少了用户自己搜索/筛选的负担；
- 是否避免把噪音带给用户；
- 是否发现了能够改变判断的证据；
- 是否最终产生了更好的行动或成果。

## 5. 当前最小可验证问题

先不做完整“个人 AI”。

只验证：

> **当用户已经有一个真实目标时，AI 能否持续从外部世界发现少量真正有价值的信息，并正确判断哪些值得进入研究/行动，而不是制造信息洪水？**

第一阶段可以用真实项目作为实验场。

成功不是“找到很多”，而是：

**发现 → 相关性判断 → 价值判断 → 证据 → 判断变化 → 下一步**

如果这一闭环不能稳定工作，就没有理由继续扩大到更宏大的主动智能、长期自主执行或多代理系统。

## 6. 对职业“信息揽客”的启发

如果未来把它发展成真实服务，不能把服务卖成：

> “我帮你搜资料。”

更有价值的服务表达应该接近：

> **“我替你盯住外部世界，把真正与你的目标有关的机会、变化、专业经验和资源筛出来，判断它们为什么值得关注，并把值得行动的部分变成可以直接使用的东西。”**

可能的交付形态包括：

- 信号简报；
- 判断/机会清单；
- 专业人士与资源连接；
- 方案与对比；
- 试点路径；
- 行动清单；
- 项目复盘。

但这些是未来的产品形态，当前不预设商业模式。

## 7. 防污染边界

本次纠正明确反对以下推导：

- “信息揽客” = 建一个万能搜索机器人；
- 信息越多 = 价值越高；
- AI 越主动 = 越好；
- Agent 越多 = 系统越强；
- Memory 越多 = 越聪明；
- 自动化任务越多 = 用户目标推进越快；
- 发现一个新概念 = 应该马上写进长期知识；
- 外部项目用了某个架构 = ai-d 就应该照搬；
- “主动发现用户不知道的问题” = AI 可以自己决定用户人生目标。

这些只能作为待验证假设，不能成为新的系统规则。

## 8. 当前核心表达

现阶段用一句话表达即可：

> **让 AI 替我盯着外面的世界，把真正值得我知道、值得我验证、值得我行动的东西带回来。**

长期再根据真实任务逐步扩展：

**带回来 → 帮我判断 → 帮我连接人/资源 → 帮我形成方案 → 帮我落地。**

这比“主动型个人超级智能体”更小、更具体，也更容易被真实任务证伪。
