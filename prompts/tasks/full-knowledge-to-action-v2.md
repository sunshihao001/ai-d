# AI-D 全量知识深层重整、专业认知调用与实际运行建设 V2.0
状态：下一轮任务候选；不是替换 AGENTS 的全局指令，不自动部署或启动。手机端 GPT 对话优先；用户不安装本地软件，不需要复制长指令。先核对最新整合分支、审查分支、现行权限及未完成事项；基线 1b3ce4e8b4c0c7e21f4eb7a154b5b55689884d95 仅供追溯。
## 0 核心任务与终点
在既有知识基础上真正完成知识语义整理、调用与成果验证。用户只需提供思想或关键决策；AI 承担专业工作。全量是覆盖目标、知识与关键依赖，不是对每个任务强行注入全部文字。复杂任务按依赖推进多个阶段；简单任务不套此流程。优先实际操作而非重复报告，阶段成果需可恢复。禁止虚构专业团队、运行、工具、完成比例或模型增益。
## 1 基线全量核查
读取 AGENTS、README、INDEX、台账、知识—行动导航、目录、已有25章候选及用户相关决策；冻结实际 Git SHA，比较七个历史分支的独有资产、PR、差异及历史回收记录。分批阅读所有有实质价值的正本与原始研究，登记读到范围、遗漏和不可访问项；树/标题扫描与完整语义阅读分别记账。检查重复、冲突、过期、孤立、来源、锚点、候选/现行混淆、原始证据与真实产物；不破坏性删除或直接合并主分支。阶段产物：覆盖台账、问题证据与修复优先级。
## 2 成熟方法及竞争路线
针对实际缺陷查成熟项目原始规范/源码/失败案例：Ars Contexta 重织，OpenWiki 版本主张，Agent Skills 按需加载，Diátaxis 信息目的，SKOS 语义关系，以及已有 Quartz/Trilium/GBrain 候选。必要时新增候选，比较原生GPT、现有GitHub入口、静态投影、外部工具及其成本/适用性。仅继承已查证的机制；不因项目流行就安装。阶段产物：机制→缺陷→适用边界→实际改动的证据表。
## 3 深层知识语义重整
沿六域、P1–P8、九阶段和跨层锚点建立一致语义，按原始知识与章节划分可独立检验的知识对象，明确稳定标识、来源版本、主张、认识状态、适用/不适用、反证、正本、相关目标、依赖、替代和更新影响。区分解释/参考/操作/学习、理论/方法/能力/实证/决策；同义合并只改索引而不抹除原证据。审查旧指令与新认知冲突，保留多种解释和独立理论价值。验证路径、必要锚点、影响关系及新旧版本；必要时用轻量机器可读目录，但不把文件边当语义边。阶段产物：有实质修订的正本、语义关系样本、未完成清单。
## 4 专业认知组合与任务生成
将初始思想复原为专业问题表征：目的、对象、环境、证据、约束、竞争解释、未知、可交付成果。按知识—行动导航识别有关路线，读取实际原件并判断条件，必要时引入需求、知识工程、领域专家、科学方法、产品、交互、工程可靠性和质量等专业职责；非独立团队不得冒称独立协作。以目标→问题→专业知识→钩子→实际对象→能力/方法→操作→证据→验收为双向链路。给出专业任务表达及依赖、阶段交付、工具、边界、反例、停机恢复；复杂任务深层展开，按需改写而不堆叠所有规则。实际直接执行已授权阶段，不要求人复制提示词。记录哪些知识真正改变行动以及为什么。
## 5 完整产品、交互与系统设计
在当前手机端入口和真实权限下，完善现有共享工作台，不将静态页面冒充实时智能体。以同源 Git 正本和版本化数据为基础，设计首页成果/待决策、目标意图、知识总览/搜索/原文/局部关系/反链、知识调用条件、研究证据、专家/成熟能力、提示词版本差异、任务阶段/依赖/实际产物与验收、变更影响、保全恢复、外部参照。每视图设计用户任务、信息层级、数据来源和对象、导航、操作反馈、空态/未知/过期/失败、权限/隐私、移动端可读性、无障碍、跨版本追溯及验收。专业细节按需披露，显示实际而非伪造状态。区分纯阅读、复制、真实工具调用和自动化。技术设计覆盖数据契约、正本/投影同步、生成可复现性、版本冲突、加载性能、日志/验收、备份与恢复、适用宿主。优先利用现有网页，保留旧25章内容；新视图先实作可用部分，并测试而非堆假按钮。非必要不自建后台、数据库、部署。
## 6 真实运行与反证
选择一个未见且有价值的专业任务，优先已有成熟能力；实际读取资料、使用授权工具、形成可核验专业成果。比较原生任务、现行入口、知识驱动表达（可比模型/工具/预算/输入），保留独立真值和未见回归题；不能启动独立会话则标 MODEL_AB=NOT_RUN，仍完成真实可检验工作。复核知识实际使用、关键正确性、遗漏、反例、任务完成质量、人工负担、总成本；不以模型自评证明智能增益。发现问题定位知识/表征/选择/执行/工具/预算/评价的最早缺陷，并修复后重测。
## 7 持久化、回读和自主接力
保存实质增量至既有正本、台账及产物，固定版本，核对实际 Git 差异、引用、原文件与证据；记录真实状态、未完成/阻塞、回滚边界。提交可审查分支，不自动合并、公开私密内容、改变定时配置或权限。生成下一轮完整专业任务规格（目标、前置知识、阶段、执行工具、验收、恢复点、UI/数据/设计影响、反证），下一次只需“继续AI-D”，由AI读取最新台账选择高价值事项；不承诺本次之外自主后台运行。若时间/工具预算限制，优先交付一个完整可复核阶段并落库，剩余明确 NOT_RUN，不用计划替代执行。
## 验收门槛
覆盖与可追溯、语义一致、知识实际改变行动、真实交付、状态可信、移动界面可用、回归与恢复。列出证据、原件链接、决策依据、未做项、下一轮任务。只在独立验证充分后主张能力提升。
