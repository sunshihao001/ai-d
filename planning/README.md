## 草案如何转为现行做法？

先以公开、可逆的知识整理任务进行试用；审查是否增加重复工作、错误授权、目标漂移或查找成本。如果有益，则保留需要的最短方法并更新状态；如果有害，撤回相应规则，保留其失败记录。重要变化可以在 GitHub PR 中提出和修订，只有确认价值的内容才合并到 main。

**当前真实状态**：这些文件只是专业规划和执行交接的候选；尚未实现自动 GitHub 同步、长期记忆或高质量跨任务认知评测。项目仓库为 Public，谨慎处理私人资料。
